# Project Roadmap

## Phase 1 (Shipped Now - Sample Site)
- Fully responsive mobile-first UI with ingredient-inspired color palette and Playfair Display typography.
- Dynamic category filtering and search functionality loaded from `menu.json`.
- Interactive WhatsApp cart drawer supporting Dine-In, Pickup, and Delivery order types.
- Birthday and event booking form with pre-filled WhatsApp routing.
- Verified aggregate rating displays (Google, Foodpanda, Facebook).
- Google Maps embed and printable QR code table menu section.

## Phase 2 (Post-Pitch / Owner Handover)
- Replace placeholder image boxes with real professional food and venue photography.
- Confirm official menu prices and input them into `menu.json`.
- Secure custom domain name (`urbancafeabbottabad.com`).
- Link official Google Business profile and verified Instagram handle.
- Integrate Google Analytics / Meta Pixel.

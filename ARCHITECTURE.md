# System Architecture

- **`index.html`**: Semantic HTML5 markup structuring all landing page sections, modals, and sticky bars.
- **`styles.css`**: CSS custom property-driven design system with responsive media queries.
- **`script.js`**: Vanilla JavaScript handling asynchronous JSON fetching, cart state management, and WhatsApp URL generation.
- **`menu.json`**: Data store decoupling menu items from presentation logic.

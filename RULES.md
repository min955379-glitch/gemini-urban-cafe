# Development & AI Rules

1. **No Emojis Anywhere**: Emojis are strictly banned in all UI elements, code comments, documentation, and commit messages[cite: 1]. Use inline SVGs for all icons.
2. **No Invented Facts**: Do not invent reviews, unverified prices, or unconfirmed quotes[cite: 1]. Mark unconfirmed items with TODO comments.
3. **Vanilla Stack Only**: No heavy frameworks (React, Vue, Tailwind CDN) are allowed so the site remains lightweight and deploys instantly on Netlify/Vercel[cite: 1].
4. **Mobile-First Accessibility**: Ensure touch targets are at least 44x44px and WCAG AA contrast standards are maintained across all color combinations[cite: 1].

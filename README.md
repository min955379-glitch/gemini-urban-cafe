# Urban Cafe & Restaurant - Website Project

Production-ready, ultra-fast one-page website for **Urban Cafe & Restaurant** located at Jadoon Plaza Phase 2, Mandian, Abbottabad. Designed as a freelance sample pitch site by **BluePeakDesign**[cite: 1].

## Local Development
1. Clone or extract all files into a local folder.
2. Run a local web server (e.g., VS Code Live Server or Python `http.server`) to test `index.html` (fetching `menu.json` requires a local server due to CORS rules).
3. Open `http://localhost:8000` in your browser.

## Editing & Customization
- **Menu Data**: Edit items, categories, and prices directly in `menu.json`.
- **Config Block**: Update contact numbers, WhatsApp numbers, and operating hours in `script.js` under the `CONFIG` object.
- **Styling**: Modify CSS variables and styles in `styles.css`.

## Deployment
Deploy instantly and for free on **Netlify** or **Vercel** by dragging and dropping the project folder.
